# Playwright Chat Flow Check

점검 일시: 2026-04-12
점검 환경:
- Frontend: `http://localhost:5173`
- Backend: `http://localhost:8080`
- AI Service: `http://localhost:8000`
- 도구: Playwright MCP

## 점검 목적

현재 챗봇이 실제 사용 흐름에서 기능별 응답이 자연스럽게 이어지는지 확인한다.

## 수행한 시나리오

### 1. 기본 대화

입력:
- `안녕`

결과:
- 정상 응답
- 기본 인사형 대화는 문제 없이 시작됨

### 2. 비교 분석

입력:
- `카카오와 네이버 비교해줘`

결과:
- 비교 요청 인식 정상
- 로딩 문구 표시: `카카오, 네이버 비교 분석 중입니다. 잠시 기다려 주세요...`
- 최종 응답 정상
- 마크다운 표와 요약 코멘트 렌더링 정상
- 출처 칩 표시 정상

관찰:
- 응답 완료까지 체감 지연이 다소 큼
- UI는 여전히 `비교 분석` 배지가 붙은 카드형 표현 사용

### 3. 비교 후 후속 질문

입력:
- `복지는 어디가 더 좋아?`

기대:
- 직전 비교 맥락을 이어받아 카카오/네이버 기준 후속 비교 응답

실제:
- 맥락을 이어받지 못함
- 일반 안내 문구로 응답:
  - `저는 취업 준비를 돕는 AI입니다. 기업 조사, 면접 준비, 자기소개서 작성 등 취업 관련 질문을 해주세요.`

판단:
- 현재 대화 컨텍스트 유지가 자연스럽지 않음
- 실사용 챗봇 기준의 가장 큰 UX 문제

### 4. 심층 분석

입력:
- `토스 심층 분석해줘`

결과:
- 요청 인식 정상
- 로딩 문구 표시 후 최종 응답 정상
- 리포트 구조, 소제목, 출처 표시 정상

관찰:
- 기능은 동작하지만 `심층 분석` 배지가 붙은 카드형 UI가 남아 있음
- 단일 대화형 assistant 경험과는 아직 거리 있음

### 5. 연봉 협상

입력:
- `카카오 개발자 연봉 협상 도와줘`
- 후속 입력: `3년차 백엔드 개발자이고 현재 연봉은 5200만원이야. 오퍼는 아직 안 받았어.`

결과:
- 첫 요청에서 연봉 협상 전용 상담 흐름으로 진입
- 추가 질문을 던진 뒤 후속 입력을 계속 받음
- 후속 답변 후 `연봉 협상 상담이 완료되었습니다.` 문구 표시

판단:
- 단발 응답이 아니라 대화형 흐름으로 이어짐
- 기능 동작 자체는 비교적 안정적

### 6. 면접 준비

입력:
- `카카오 면접 준비해줘`
- 후속 입력: `지원 동기 답변 예시도 만들어줘`

결과:
- 첫 요청에서 면접 준비 가이드 생성
- 회사 키워드, 예상 질문, 역질문, 주의점 등 구조화 응답 정상
- 후속 질문도 같은 면접 준비 맥락 안에서 이어짐

판단:
- 면접 준비 흐름은 자연스러운 편
- 리포트 생성 후 후속 상담이 이어지는 구조가 잘 동작함

### 7. 자기소개서 작성

입력:
- `카카오 자소서 써줘`
- 후속 입력: `좀 더 짧고 담백하게 다듬어줘`

결과:
- 자기소개서 초안 생성 정상
- 지원 동기, 성장 과정, 직무 역량, 입사 후 포부 구조 정상
- 후속 수정 요청도 같은 맥락에서 계속 처리됨

판단:
- 초안 생성 및 수정 흐름 모두 정상
- 실제 사용 흐름에 가까운 형태로 동작

### 8. 자기소개서 피드백

입력:
- `자소서 피드백 받고 싶어`
- 후속 입력: `건너뛰기`

결과:
- 바로 에러를 내지 않고 추가 정보 입력을 요청
- 채용공고 URL 입력 또는 `건너뛰기` 선택 흐름 정상
- `건너뛰기` 이후 `자기소개서를 분석 중입니다. 잠시 기다려 주세요...` 문구 표시
- 네트워크 기준 후속 처리도 `POST /chat/respond` 경유로 확인

관찰:
- UI 기준으로는 응답 체감이 느림
- 짧은 대기 시간 내에는 완료 결과가 바로 보이지 않았음

판단:
- 백엔드 호출 자체는 성공
- 프론트 반영 지연 또는 응답 대기 시간이 긴 편

### 9. 뉴스 검색

입력:
- `최근 뉴스 알려줘`

결과:
- 뉴스 검색 흐름 정상 진입
- 여러 뉴스 항목을 리스트 형태로 반환
- 출처 칩 표시 정상

관찰:
- 회사명을 특정하지 않으면 다소 넓은 범주의 뉴스가 나옴
- "내가 원하는 최근 뉴스"와 결과 범위가 다를 가능성 있음

### 10. 일반 취업 상담

입력:
- `백엔드 취업 준비 팁 알려줘`

결과:
- 일반 상담형 응답 정상
- 회사 맥락 없이도 취업 팁을 리스트 형태로 답변

판단:
- 일반 대화 fallback 은 무리 없이 동작

### 11. 모의 면접 시작

입력:
- `카카오 모의 면접 시작해줘`

결과:
- 회사 정보와 함께 면접 질문 목록을 생성
- 첫 응답 자체는 정상
- 회사 소개, 주요 사업, 면접 질문, 참고 출처까지 구조화되어 표시됨

판단:
- "모의 면접 시작" 진입은 정상
- 사용자가 바로 답변을 이어갈 수 있는 형태로 보임

### 12. 모의 면접 후속 답변

입력:
- `카카오의 다양한 서비스 데이터를 연결하는 방식과 사용자 경험 개선에 기여하는 점이 흥미로워 지원했습니다.`

기대:
- 직전 모의 면접 맥락을 이어받아 답변 피드백 또는 다음 면접 질문 제시

실제:
- 면접 피드백이 아니라 `카카오 자기소개서 초안`이 생성됨
- 응답 메타도 `카카오 자기소개서 작성`으로 표시됨

판단:
- 모의 면접 후속 턴 라우팅이 잘못 연결되어 있음
- 현재 상태로는 "대화형 모의 면접"이 자연스럽게 이어지지 않음
- 비교 후 후속 질문 누락과 별개의 고우선순위 UX 결함

### 13. 채용공고 추천

입력:
- `채용공고 추천해줘`

결과:
- 별도 추천 흐름으로 진입하지 않음
- 일반 안내 문구로 응답:
  - `저는 취업 준비를 돕는 AI입니다. 기업 조사, 면접 준비, 자기소개서 작성 등 취업 관련 질문을 해주세요.`

판단:
- 랜딩 문구에는 채용공고 추천/적합도 기능이 보이지만, 현재 채팅 UI에는 연결되어 있지 않음
- 실사용 기준으로는 "있는 기능처럼 보이지만 실제로는 호출되지 않는 상태"에 가깝다

## 네트워크/콘솔 관찰

### 네트워크

확인된 주요 요청:
- `POST /auth/login` → `200`
- `GET /companies` → 초기 일부 `403`, 이후 `200`
- `GET /conversations` → 초기 일부 `403`, 이후 `200`
- `POST /chat/respond` → `200`

관찰:
- 로그인 직후 초기 데이터 로드 타이밍에서 인증 상태가 잠깐 불안정해 보임

### 콘솔

확인된 에러:
- `GET /companies` `403`
- `GET /conversations` `403`
- 브라우저 확장프로그램 content script 에러

확장프로그램 에러:
- `Could not establish connection. Receiving end does not exist.`

판단:
- `content_script.js` 에러는 앱보다는 브라우저 확장프로그램 영향으로 보임

## 종합 판단

현재 상태는 다음과 같음:

- 기본 대화: 동작
- 비교 분석: 동작
- 심층 분석: 동작
- 연봉 협상: 동작
- 면접 준비: 동작
- 자기소개서 작성: 동작
- 자기소개서 피드백: 호출 성공, 체감 지연 큼
- 뉴스 검색: 동작
- 일반 취업 상담: 동작
- 모의 면접 시작: 동작
- 모의 면접 후속 답변: 오동작
- 채용공고 추천: 미연결 또는 미구현
- 후속 질문 맥락 유지: 일부 시나리오에서 부자연스러움

즉, 기능별 응답은 대부분 실행되지만 `하나의 자연스러운 대화 흐름`으로 보기는 아직 어려움.

## 우선 수정 권장

1. 비교/심층분석 이후 후속 질문이 직전 맥락을 이어받도록 개선
2. 모의 면접 후속 답변이 자기소개서 작성으로 잘못 라우팅되는 문제 수정
3. 채용공고 추천/적합도 기능이 실제 채팅에서 동작하는지 연결 상태 정리
4. `비교 분석`, `심층 분석` 카드형 UI를 일반 assistant 메시지 스타일로 통합
5. 로그인 직후 `companies`, `conversations` 초기 `403` 발생 원인 점검
6. 자기소개서 피드백 응답의 체감 지연 또는 프론트 반영 타이밍 점검

## 모의 면접 기능 분리 제안

현재 모의 면접은 일반 채팅 내부 기능으로 붙어 있어 후속 턴 라우팅이 흔들리고, 일반 질의응답과 UX 성격도 다르다.

제안:
- 모의 면접을 일반 채팅과 분리된 별도 기능으로 제공
- 진입 위치는 `관심 기업` 또는 기업 상세 진입 후 `모의 면접 시작`
- 사용자는 기업을 선택하고 면접 세션에 들어감

권장 UX:
- AI 면접관이 음성으로 질문을 제시
- 사용자는 음성으로 답변
- STT로 답변을 텍스트화
- AI가 답변 피드백과 다음 질문 생성
- TTS로 다음 질문 재생

MVP 권장 범위:
- 관심 기업에서 기업 선택
- 직무/난이도 선택
- 질문 음성 재생
- 사용자 음성 녹음 및 전송
- 답변 피드백 + 꼬리 질문 생성
- 세션 종료 후 종합 피드백 제공

판단:
- 이 기능은 일반 텍스트 챗봇의 하위 기능보다 별도 인터뷰 세션에 가까움
- ChatGPT형 메인 채팅 UI를 유지하려면 분리하는 편이 자연스럽다
- Siri처럼 완전 실시간 음성 대화는 후순위로 두고, 초기에는 `질문 음성 재생 + 답변 녹음 + 다음 질문 생성` 구조가 현실적이다
